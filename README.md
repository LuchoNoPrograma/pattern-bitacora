# Bitacora de patrones

Me olvide el patron de un telefono y necesitaba anotar cuales ya habia probado.
Hice esta pagina para dibujar cada candidato y marcarlo cuando no funciona.

Los intentos quedan guardados en el navegador. La pagina no usa cuentas, no
manda los patrones a ningun servidor y tampoco necesita instalar nada.

## Uso

1. Dibuja un patron.
2. Si no funciono, marca `No funciono`.
3. Cuando vuelvas a dibujar el mismo patron aparecera en rojo.

Tambien puedes abrir un intento anterior, ocultar las miniaturas, borrar
registros o guardar cualquier patron como una imagen PNG.

Los iconos son de [Lucide](https://lucide.dev/) y estan incluidos directamente
en la pagina para no cargar una libreria externa.
